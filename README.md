# TaskFlow

App interna di gestione task. Backend in FastAPI, frontend statico.

## Setup rapido

```
cd backend
pip install -r requirements.txt
uvicorn app:app --reload
```

Poi apri i file in `frontend/pages/` nel browser (o servili con un server statico a piacere).

Progetto in fase di sistemazione, alcune pagine sono più curate di altre.
